# Rhombix Technologies - Project 1

## Linux Basics & Command-Line Practice

### Objective

The objective of this project is to practice fundamental Linux command-line operations, including file and directory management, file permissions, system resource monitoring, and package management.

### Environment

- Operating System: Ubuntu Linux
- Shell: Bash
- Platform: AWS EC2
- Package Manager: APT

### Commands Practiced

#### Basic Commands

- `pwd` - Displays the current working directory.
- `whoami` - Displays the current logged-in user.
- `ls` - Lists files and directories.
- `cd` - Changes the current working directory.

#### Directory Management

- `mkdir` - Creates new directories.
- `find` - Searches for files and directories.

#### File Management

- `touch` - Creates empty files.
- `cat` - Displays file contents.
- `echo` - Writes text to a file.
- `cp` - Copies files.
- `mv` - Moves or renames files.

#### File Permissions

- `ls -l` - Displays file permissions and ownership.
- `chmod` - Changes file permissions.

#### System Monitoring

- `free -h` - Displays memory usage.
- `df -h` - Displays disk usage.
- `du -sh` - Displays directory size.
- `top` - Displays running processes and system resource usage.

#### Package Management

- `apt update` - Updates package information.
- `apt install` - Installs packages.
