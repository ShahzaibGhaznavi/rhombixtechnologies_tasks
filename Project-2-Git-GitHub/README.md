# Project 2 - Version Control with Git & GitHub

## Objective

The objective of this project is to understand and practice version control using Git and GitHub.

## Git Concepts Practiced

### Repository Management

- `git init` - Initializes a new Git repository.
- `git clone` - Creates a local copy of a remote repository.

### Tracking Changes

- `git status` - Shows the current state of the working directory.
- `git add` - Adds changes to the staging area.
- `git commit` - Records staged changes in the local repository.

### Remote Operations

- `git push` - Uploads local commits to the remote GitHub repository.
- `git pull` - Fetches and integrates the latest changes from the remote repository.

### Branch Management

- `git branch` - Lists available branches.
- `git switch -c` - Creates and switches to a new branch.
- `git merge` - Integrates changes from one branch into another.

## Workflow Demonstrated

1. Cloned the GitHub repository using `git clone`.
2. Created and modified a file.
3. Checked changes using `git status`.
4. Staged the file using `git add`.
5. Created a commit using `git commit`.
6. Pushed changes to GitHub using `git push`.
7. Pulled updates using `git pull`.
8. Created a feature branch.
9. Made changes on the feature branch.
10. Merged the feature branch into `main`.
11. Pushed the updated `main` branch to GitHub.
